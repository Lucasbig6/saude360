# SIGDATA — Design Principles

## Produto

SIGDATA é uma plataforma profissional de inteligência
e análise de dados em saúde pública.

A interface deve transmitir:

- confiança
- precisão
- clareza
- eficiência
- maturidade institucional

## Direção visual

A interface deve parecer um software profissional de dados.

Referências conceituais:

- Power BI
- Linear
- Vercel
- Notion
- ferramentas profissionais de analytics

Não copiar visualmente nenhuma delas.

## Evitar

- excesso de cards
- gradientes decorativos
- glassmorphism
- sombras exageradas
- bordas excessivamente arredondadas
- excesso de ícones
- dashboards com aparência de template
- elementos decorativos sem função
- excesso de cores
- títulos gigantes
- CTAs chamativos sem necessidade

## Regra principal

Informação deve ter prioridade sobre decoração.

Antes de adicionar um elemento visual,
pergunte:

"Isso ajuda o usuário a entender ou executar alguma coisa?"

Se não, provavelmente não deve existir.
